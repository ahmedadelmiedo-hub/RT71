# قرار محرك الصوت

توقف اختبار الفيديو الكامل عند تنزيل XTTS-v2 لأن رخصته تشترط قبول شروط Coqui Public Model License. تنص الرخصة على قصر استخدام النموذج ومخرجاته على الاستخدام غير التجاري، لذلك لا يُعتمد للمسار الموجه لقناة قد تُنشر للعامة قبل حسم ملاءمة الرخصة.

كبديل مفتوح المصدر، يعرض مشروع Habibi-TTS دعمًا للعربية، ومنها النموذج المتخصص للهجة المصرية. يذكر المشروع أن كوده مرخص MIT وأن نماذجه المتخصصة المصرية مرخصة Apache 2.0، بينما تختلف رخصة النموذج الموحد وبعض النماذج الأخرى.
