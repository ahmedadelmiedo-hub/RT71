# إعداد تفويض YouTube للنشر التلقائي

أُنشئ عميل OAuth مكتبي باسم `RT71 YouTube Auto Publisher` ضمن مشروع Google Cloud المرتبط بمالك القناة. واجهة **YouTube Data API v3** مفعّلة للمشروع، ويُستخدم نطاق `https://www.googleapis.com/auth/youtube.upload` لتوليد رمز تجديد مشفّر يحفظ في أسرار GitHub فقط.

لا يحتوي هذا الملف على معرّف سري أو رمز وصول أو بيانات اعتماد قابلة للاستخدام. الإذن المطلوب يتيح إدارة فيديوهات YouTube لغرض الرفع التلقائي للحلقات والشورتس.

تمت إعادة تفويض عميل GitHub المحلي لأن الاعتماد السابق يملك صلاحية المستودع لكنه لا يملك وصول كتابة إلى أسرار GitHub Actions. التفويض الجديد مخصص لتمكين حفظ اعتماد YouTube المشفّر في أسرار المستودع فقط.

## حالة الإعداد والتحقق

حُفظ الاعتماد المشفّر في سر المستودع `YOUTUBE_OAUTH_B64`، وضُبط متغير المستودع `YOUTUBE_AUTOPUBLISH` على `true` لتفعيل النشر العام في التشغيلات المجدولة. لا تحتوي هذه الوثيقة ولا سجل Git على قيمة الاعتماد أو رمز التجديد أو سر العميل.

نجح اختبار النشر الكامل في التشغيل [`32435314424`](https://github.com/ahmedadelmiedo-hub/RT71/actions/runs/32435314424) بتاريخ 21 أغسطس 2026. اكتملت خطوة استعادة الاعتماد وخطوة رفع الفيديو الطويل والشورت بنجاح، ما يثبت أن الإعداد الفعلي لسير العمل يعمل دون إدخال يدوي.
