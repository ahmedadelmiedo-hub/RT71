# حالة جلسة نشر YouTube Studio

تم فتح YouTube Studio للقناة `@AlMalaf71` من جلسة المالك المصرح بها. استُخدمت الجلسة في النشر اليدوي الأول، ثم استُكمل اعتماد OAuth لتمكين الرفع العام تلقائيًا عبر GitHub Actions.

تتبع الجلسة ترتيبًا آمنًا: إكمال بيانات الفيديو الطويل، اختياره عامًا، ثم رفع الشورت، ووضع رابط الحلقة الطويلة في وصفه وتعيينها كفيديو ذي صلة داخل YouTube Studio.

## تحقق السلامة

أثناء تجربة الإرفاق ظهرت معاينة لملف بعنوان افتراضي مختلف ولا تطابق الهوية البصرية لملف RT71 النهائي؛ تُركت على الحالة الخاصة ولم تُعلن. يجب عدم جعل هذا الملف عامًا، ويستلزم الرفع متابعة اختيار ملف `final.mp4` و`short.mp4` من أثر التشغيل النهائي فقط.

## نتيجة النشر

نُشرت الحلقة `episode-20260820-2346` علنًا بعنوانها ووصفها المعتمدين، ونُشر شورتها المصاحب علنًا مع رابط مباشر إلى الحلقة الطويلة في الوصف.

- الحلقة الطويلة: `https://youtu.be/BWM8bDePA8E`
- الشورت: `https://youtube.com/shorts/NWlryvnXxsI?feature=share`

طلب YouTube Studio إكمال إثبات الهوية للوصول إلى ميزة «فيديو ذي صلة» الأصلية في مشغل Shorts. لم تُستكمل عملية إثبات الهوية، لذلك يظل رابط الحلقة الطويلة في وصف الشورت هو وسيلة الربط الفعّالة حاليًا.

## اختبار الأتمتة المكتمل
