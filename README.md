# الملف 71 — خط إنتاج حلقة خيالية

ينشئ هذا المستودع حلقة سردية **خيالية أصلية** لقناة [@AlMalaf71](https://www.youtube.com/@AlMalaf71). يُنتج المسار نصًا عربيًا، وستة مشاهد بصرية تجريدية أصلية، وتعليقًا بصوت المذيع المخزن سرًا، وفيديو MP4 مدته نحو خمس دقائق.

> لا يرفع المسار أي فيديو إلى YouTube ولا يدّعي أن الحلقات قضايا واقعية. الناتج محفوظ للمراجعة اليدوية فقط.

## التشغيل

يقع ملف الهوية والسياسات في `config/channel_profile.json`. يعمل مسار GitHub Actions كل أربع ساعات وفق التوقيت العالمي UTC، ويمكن تشغيله يدويًا من تبويب **Actions** مع خيار `dry_run` لتوليد النص والبيانات فقط.

تحتاج عملية التعليق الصوتي إلى سر المستودع `VOICE_REFERENCE_B64`، وهو مرجع صوت المذيع ولا يُحفظ في الملفات العامة. يستخدم المسار XTTS v2 في وضع مراجعة خاص غير تجاري، مع مرجع الصوت الذي يقدمه مالك القناة. تحفظ GitHub المخرجات كـ Artifact لمدة 14 يومًا، ويبقى النشر إلى YouTube معطّلًا.
