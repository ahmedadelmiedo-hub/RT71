# الملف 71 — خط إنتاج حلقة خيالية

ينشئ هذا المستودع حلقة سردية **خيالية أصلية** لقناة [@AlMalaf71](https://www.youtube.com/@AlMalaf71). يُنتج المسار نصًا عربيًا، وستة مشاهد بصرية تجريدية أصلية، وتعليقًا بصوت المذيع المخزن سرًا، وفيديو MP4 مدته نحو خمس دقائق.

> جميع الحلقات قصص خيالية أصلية ولا تُقدَّم بوصفها قضايا أو أحداثًا واقعية. عند تفعيل النشر، تُنشر الحلقة والشورت المرافق علنًا على القناة المعتمدة فقط.

## التشغيل

يقع ملف الهوية والسياسات في `config/channel_profile.json`. يعمل مسار GitHub Actions كل أربع ساعات وفق التوقيت العالمي UTC، ويمكن تشغيله يدويًا من تبويب **Actions** مع خيار `dry_run` لتوليد النص والبيانات فقط. ينفّذ التشغيل المجدول النشر العام تلقائيًا عندما تكون قيمة متغير المستودع `YOUTUBE_AUTOPUBLISH` مساوية لـ `true`.

تحتاج عملية التعليق الصوتي إلى سر المستودع `VOICE_REFERENCE_B64`، وهو مرجع صوت المذيع ولا يُحفظ في الملفات العامة. كما يحتاج النشر إلى سر `YOUTUBE_OAUTH_B64` الذي يحتوي اعتماد رفع YouTube المشفّر. يستخدم المسار XTTS v2 في وضع غير تجاري مع مرجع الصوت الذي يقدمه مالك القناة، وتحفظ GitHub المخرجات كـ Artifact لمدة 14 يومًا.

## الاختبار

```bash
python3 -m unittest discover -s tests -v
```
